# Дипломный проект: Аппроксимация координатных преобразований ДЗЗ

## Соглашение о пикселе
В проекте используется **соглашение о центре пикселя** (как в GDAL). 
Это означает, что координаты (0, 0) соответствуют центру левого верхнего пикселя. 
В классе `RPC` (в методах `forward` и `forward_with_jacobian`) к вычисленным координатам `n` и `m` прибавляется `0.5`.
